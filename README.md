# Incubyte Gmail Compose Testing Assignment

## Objective
Manual testing assignment for validating Gmail compose functionality.

The scope of testing includes validating the email compose feature in Gmail for sending an email with:
- Subject: "Incubyte"
- Body: "QA test for Incubyte"

- Traditional Style Test Cases
- BDD Style Test Scenarios
- Positive Test Cases
- Negative Test Cases
